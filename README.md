# DeepSeek-R1 na Railway

Este repositório contém um exemplo de como rodar o modelo DeepSeek-R1-Distill-Qwen-7B na plataforma Railway.

## Como usar

1. Clone este repositório.
2. Crie um novo projeto no Railway e conecte este repositório.
3. Railway irá construir a imagem Docker automaticamente.
4. Acesse os logs para verificar a execução do modelo.

## Observações

- O modelo DeepSeek-R1-Distill-Qwen-7B é mais leve e pode ser executado em uma única GPU, como a NVIDIA RTX 4090.
- Certifique-se de ter uma chave API válida para o modelo DeepSeek-R1.
